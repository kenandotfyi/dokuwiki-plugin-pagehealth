# Page Health

This local DokuWiki action plugin fades internal page links when the target
page has no body content outside headings. It does not modify the `nspages`
plugin.

The browser collects existing internal page links from each rendered page and
submits their IDs in batches of up to 500. The **Admin → Page Health** page can
scan all wiki pages in batches of up to 500, so existing pages are classified
without requiring a visit or an `nspages` listing. The admin page shows scan
progress, counts, and a list of no-content pages. The server stores
classifications in one cache index and reads/classifies source only for IDs
that are not in that index during the initial scan. Successful page saves
refresh the saved classification. Unreadable pages are left with the normal
appearance. Links with `rel="tag"` are skipped because the Tag plugin renders
tag views as virtual links rather than wiki pages.

The admin-triggered scan processes a bounded batch per request and resumes if
interrupted. Later views read the saved index instead of reopening each page
source. The index is versioned so changes to the heading rules trigger
reclassification.
The classifier ignores DokuWiki heading lines, Markdown ATX and Setext
headings, HTML heading blocks, comments, and common page-control directives.
Any other non-whitespace source counts as content. Pages changed directly on
disk bypass DokuWiki's save hook; clear the `data/cache/pagehealth` directory
to reclassify those pages.

The Admin → Page Health page also provides appearance settings for no-content
links: normal and hover colors, opacity, text decoration and line style, and
italic text. These settings are also available in DokuWiki's Configuration
Manager.

Use `~~PAGEHEALTH~~` in a wiki page to display the current healthy and
no-content page counts. Until the admin full scan completes, the syntax labels
its figures as partial results. Counts include only pages the current reader
can access.

To enable it, refresh the plugin list in DokuWiki's Extension Manager and
enable **Page Health** if it is not enabled automatically. Its cache is stored
under DokuWiki's normal cache directory and can be regenerated by clearing
that plugin cache directory.
